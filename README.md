# YouTube Relaxing & Meditation Bot 🧘‍♂️✨

ဤ Bot သည် YouTube ပေါ်တွင် **Relaxing**, **Meditation** နှင့် **Deep Sleep** ဗီဒီယိုများကို အလိုအလျောက် ဖန်တီး၍ တင်ပေးနိုင်သော Professional အဆင့်မြင့် စနစ်တစ်ခု ဖြစ်ပါသည်။

## 🌟 အဓိက လုပ်ဆောင်ချက်များ (Core Features)

*   **Cinematic Visuals**: Pexels API ကို သုံး၍ 4K/HD အရည်အသွေးရှိသော သဘာဝရှုခင်း ဗီဒီယိုများကို အလိုအလျောက် ရွေးချယ်ပေးပါသည်။
*   **Copyright-Free Music**: API မလိုဘဲ Copyright ကင်းလွတ်သည့် Relaxing သီချင်းများကို အလိုအလျောက် ရှာဖွေဒေါင်းလုဒ်ဆွဲပေးပါသည်။
*   **AI Metadata (Gemini 1.5 Flash)**: နောက်ဆုံးပေါ် Gemini AI ကို သုံး၍ လူသားဆန်သော SEO Title, Description နှင့် Tags များကို ဖန်တီးပေးပါသည်။
*   **Automated Thumbnails**: ဗီဒီယိုအတွက် ဆွဲဆောင်မှုရှိသော Cover (Thumbnail) ကို အလိုအလျောက် ဖန်တီးပြီး YouTube ပေါ် တိုက်ရိုက်တင်ပေးပါသည်။
*   **YouTube Chapters & CTA**: ဗီဒီယိုထဲတွင် Timestamps (Chapters) များနှင့် Subscribe လုပ်ရန် တိုက်တွန်းချက်များကို အလိုအလျောက် ထည့်သွင်းပေးပါသည်။
*   **AI Disclosure Setting**: YouTube ၏ monetization စည်းမျဉ်းများနှင့် ကိုက်ညီစေရန် "Altered or Synthetic Content" setting ကို အလိုအလျောက် On ပေးပါသည်။
*   **Telegram Notifications**: ဗီဒီယိုတင်သည့် အခြေအနေ (Progress) နှင့် ရလဒ်များကို Telegram သို့ အသေးစိတ် ပို့ပေးပါသည်။

## 🛠 လိုအပ်သော API Keys (Setup)

`.env` ဖိုင်တွင် အောက်ပါတို့ကို ဖြည့်စွက်ပေးရန် လိုအပ်ပါသည်-

1.  **YouTube Credentials**: Client ID, Secret နှင့် Refresh Token။
2.  **Telegram Credentials**: Bot Token နှင့် Chat ID။
3.  **Pexels API Key**: [Pexels API](https://www.pexels.com/api/) မှ ရယူပါ။
4.  **Gemini API Key**: [Google AI Studio](https://aistudio.google.com/) မှ ရယူပါ။

## 🚀 စတင်အသုံးပြုပုံ (Usage)

၁။ လိုအပ်သော dependencies များ သွင်းရန်-
```bash
npm install
```

၂။ Bot ကို စတင် run ရန်-
```bash
npm start
```

## 📅 GitHub Actions (Automation)

ဤ Bot ကို GitHub Actions တွင် ထည့်သွင်းထားပြီး ဖြစ်သဖြင့် သင်၏ Repository **Secrets** ထဲတွင် API Key များကို ထည့်သွင်းပေးရုံဖြင့် နေ့စဉ် အလိုအလျောက် ဗီဒီယိုများ တင်ပေးနေမည် ဖြစ်ပါသည်။
